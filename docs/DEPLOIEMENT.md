# Mise en ligne

👉 **Le guide de déploiement a déménagé : voir [`DEPLOY.md`](../DEPLOY.md)**, à la racine
du projet.

Il couvre, pas à pas et pour un profil non-développeur :

- lancer l'application sur son ordinateur ;
- la mettre en ligne gratuitement (Railway, Docker, autres hébergeurs) ;
- toutes les variables d'environnement ;
- tester l'application native sur un vrai téléphone (Expo Go) ;
- compiler un `.apk` Android et publier sur les magasins.

Ce fichier ne contient plus rien d'autre : deux guides de déploiement finiraient par se
contredire, et c'est celui de la racine qui fait foi.
